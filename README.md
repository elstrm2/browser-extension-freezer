# browser-extension-freezer

Block Chrome/Chromium extension auto-updates via Enterprise Policies.

## Usage

**Linux** (tested on Arch/EndeavourOS):
```bash
./freeze-extensions.sh
```

**Windows** (tested on Windows 10):
```powershell
.\freeze-extensions.ps1
```

## Verify

Restart browser → `chrome://policy/`

## Supported

Chrome, Chromium, Brave, Vivaldi, Opera, Edge
